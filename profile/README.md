Government data published today may be gone, paywalled, or reshaped tomorrow. So we archive: monthly toll-plaza dumps, daily CoWIN availability, every electoral affidavit. The repo *is* the dataset — clone it, cite it, re-run it.

## 🗳️ Elections & Transparency

| Repo | What it holds |
|------|--------------|
| [`ElectoralBondsData`](https://github.com/DigitalIndiaArchiver/ElectoralBondsData) | Electoral bonds data |
| [`AffidavitManagement`](https://github.com/DigitalIndiaArchiver/AffidavitManagement) | Affidavits of accepted election candidates, post-2019 |

## 🍚 Welfare & Food Security

| Repo | What it holds |
|------|--------------|
| [`ONORC-Data`](https://github.com/DigitalIndiaArchiver/ONORC-Data) | One Nation One Ration Card — integrated public distribution management data |
| [`FPS_Shops`](https://github.com/DigitalIndiaArchiver/FPS_Shops) | Data dump of all Public Distribution System (fair price) shops in India |
| [`CoWIN-Availability`](https://github.com/DigitalIndiaArchiver/CoWIN-Availability) | CoWIN vaccination slot availability archive |
